TIPO TESTMULTIPLE CHOICE

¿Cuál de las siguientes frases es información, y no un simple dato?Which of the following sentences is information, not just a raw datum?

  • A) "18"
  • A) "18"
  • B) "18 personas se han matriculado hoy en el curso de DAM"
  • B) "18 people enrolled in the DAM course today"
  • C) "personas"
  • C) "people"
Ver soluciónShow solution

B. "18" es un dato aislado sin contexto; "personas" es sólo una unidad. La opción B añade contexto (qué, cuándo, cuánto) que permite entender e interpretar el hecho — eso es información. Si además esa información se usa para decidir, por ejemplo, abrir un segundo grupo, se convierte en conocimiento. "18" is an isolated datum with no context; "people" is just a unit. Option B adds context (what, when, how many) that lets the fact be understood and interpreted — that is information. If that information is then used to decide something, like opening a second group, it becomes knowledge.

VERDADERO / FALSOTRUE / FALSE

Indica si cada afirmación sobre ficheros de texto y binarios es verdadera o falsa.Say whether each statement about text and binary files is true or false.

  1. 1. Un fichero .csv es un fichero de texto plano.
  2. 1. A .csv file is a plain text file.
  3. 2. Un fichero .jpg se puede leer con normalidad en el Bloc de notas.
  4. 2. A .jpg file can be read normally in Notepad.
  5. 3. Los ficheros que componen una base de datos (como los .ibd de MariaDB) suelen ser binarios.
  6. 3. The files that make up a database (like MariaDB's .ibd files) are usually binary.
  7. 4. El acceso secuencial permite saltar directamente a cualquier registro.
  8. 4. Sequential access lets you jump straight to any record.
Ver soluciónShow solution

1. Verdadero. El CSV es texto separado por comas, legible en cualquier editor.

2. Falso. Un JPG es binario: al abrirlo en un editor de texto se ven símbolos ilegibles.

3. Verdadero. Los ficheros internos de un SGBD codifican la información en binario siguiendo un estándar propio.

4. Falso. Eso describe el acceso directo o aleatorio; el secuencial obliga a recorrer todos los registros anteriores.

1. True. CSV is comma-separated text, readable in any editor.

2. False. A JPG is binary: opening it in a text editor shows unreadable symbols.

3. True. A DBMS's internal files encode information in binary, following its own standard.

4. False. That describes direct/random access; sequential access requires passing through every earlier record.

CASO PRÁCTICOCASE STUDY

Una empresa tiene un fichero empleados_rrhh.csv gestionado por Recursos Humanos y otro fichero trabajadores_nomina.csv gestionado por Contabilidad, ambos con el nombre y el DNI de cada trabajador.A company has a file employees_hr.csv managed by HR and another file workers_payroll.csv managed by Accounting, both containing each worker's name and ID number.

¿Qué problema típico de los ficheros de texto está sufriendo esta empresa? ¿Y qué pasaría si un trabajador cambia de nombre legal y RRHH actualiza su fichero pero Contabilidad no?Which typical problem of flat text files is this company suffering from? And what would happen if a worker changes their legal name and HR updates their file but Accounting doesn't?

Ver soluciónShow solution

Redundancia de datos: el mismo dato (nombre y DNI) se guarda por duplicado en dos ficheros distintos, sin ningún formato común entre aplicaciones. Si RRHH actualiza el nombre y Contabilidad no, aparece inconsistencia de información: la misma persona tendrá dos nombres diferentes según a qué fichero se consulte, lo que puede generar errores en nóminas, facturas o comunicaciones oficiales. Este es exactamente el problema que resuelven las bases de datos, donde el dato existe en un único lugar (redundancia mínima). Data redundancy: the same data (name and ID number) is duplicated across two different files, with no shared format between the applications. If HR updates the name and Accounting doesn't, you get information inconsistency: the same person will have two different names depending on which file is checked, which can cause errors in payroll, invoices or official communications. This is exactly the problem databases solve, since each piece of data exists in a single place (minimal redundancy).

CENTRALIZADA VS. DISTRIBUIDACENTRALISED VS. DISTRIBUTED

Una startup empieza con 200 usuarios y una base de datos MySQL en un único servidor. Dos años después tiene 40 millones de usuarios repartidos por varios continentes.A startup begins with 200 users and a MySQL database on a single server. Two years later it has 40 million users spread across several continents.

¿Qué arquitectura tenía al principio? ¿Hacia qué tipo de arquitectura debería evolucionar y qué ventaja principal obtiene, y a qué coste?What architecture did it have at first? What type of architecture should it evolve towards, and what is the main benefit — at what cost?

Ver soluciónShow solution

Al principio tiene una arquitectura centralizada cliente-servidor: un único servidor MySQL atendiendo a todos los clientes. Con 40 millones de usuarios repartidos globalmente, debería migrar a una arquitectura distribuida, particionando o replicando los datos entre varios servidores geográficamente cercanos a los usuarios. La ventaja principal es la robustez y el rendimiento (menor latencia, tolerancia a fallos de un servidor); el coste es una mayor complejidad para sincronizar los datos entre nodos y mantener la consistencia. At first it has a centralised client-server architecture: a single MySQL server serving every client. With 40 million users spread globally, it should migrate to a distributed architecture, partitioning or replicating data across several servers geographically close to users. The main benefit is robustness and performance (lower latency, tolerance to a single server failing); the cost is added complexity in syncing data between nodes and keeping consistency.

SGBD y transaccionesDBMS and transactions

8
ACID

Un banco realiza una transferencia de 100 € entre dos cuentas. A mitad de la operación (ya se ha restado el dinero de la cuenta origen, pero aún no se ha sumado a la cuenta destino), el servidor sufre un corte de luz.A bank makes a €100 transfer between two accounts. Halfway through the operation (the money has already been subtracted from the source account, but not yet added to the destination account), the server loses power.

¿Qué propiedad ACID debe garantizar que, al reiniciar el sistema, los 100 € no desaparezcan? Explica qué debería ocurrir.Which ACID property must guarantee that, once the system restarts, the €100 doesn't disappear? Explain what should happen.

Ver soluciónShow solution

La atomicidad. La transacción "transferir 100 €" se compone de dos operaciones (restar y sumar) que deben tratarse como un bloque indivisible: o se ejecutan las dos, o no se ejecuta ninguna. Al detectar el fallo, el SGBD debe hacer un ROLLBACK y devolver los 100 € a la cuenta origen, dejando el sistema como si la transacción nunca hubiera empezado. (La durabilidad entraría en juego si el corte llega justo después de confirmar el COMMIT: en ese caso los datos ya escritos no se deben perder.) Atomicity. The "transfer €100" transaction is made up of two operations (subtract and add) that must be treated as one indivisible unit: either both run, or neither does. On detecting the failure, the DBMS must ROLLBACK and return the €100 to the source account, leaving the system as if the transaction had never started. (Durability would come into play if the power cut happened right after the COMMIT was confirmed: in that case the already-written data must not be lost.)

TIPO TESTMULTIPLE CHOICE

¿Cuál de estas afirmaciones sobre un SGBD es correcta?Which of these statements about a DBMS is correct?

  • A) MySQL es una base de datos.
  • A) MySQL is a database.
  • B) Un SGBD es el software que crea, manipula y administra bases de datos, y sirve de interfaz entre el usuario y los datos.
  • B) A DBMS is the software that creates, manipulates and administers databases, acting as the interface between the user and the data.
  • C) Un SGBD sólo puede gestionar una base de datos a la vez.
  • C) A DBMS can only manage one database at a time.
Ver soluciónShow solution

B. MySQL, Oracle o MongoDB son SGBD, no bases de datos: la base de datos es la información en sí, organizada; el SGBD es el software que la gestiona. Un mismo SGBD puede además administrar varias bases de datos a la vez (por ejemplo, MariaDB gestiona una carpeta "data" con varias bases de datos dentro). MySQL, Oracle and MongoDB are DBMSs, not databases: the database is the actual organised information; the DBMS is the software that manages it. A single DBMS can also administer several databases at once (for example, MariaDB manages a "data" folder holding several databases).

Protección de datosData protection

11
CASO PRÁCTICOCASE STUDY

Una aplicación de citas médicas online pide al usuario, además de nombre y teléfono, que indique su religión "para adaptar el trato del personal", sin explicar más ni pedir un consentimiento distinto para ese dato.An online medical appointment app asks the user, besides name and phone number, to state their religion "to tailor how staff treat them," without further explanation or a separate consent for that field.

¿Qué está haciendo mal esta aplicación según la LOPDGDD/RGPD? ¿Qué tipo de dato es la religión y qué debería haber hecho la empresa?What is this app doing wrong according to the LOPDGDD/GDPR? What kind of data is religion, and what should the company have done?

Ver soluciónShow solution

La religión es un dato sensible según la LOPDGDD, junto con el origen étnico, la ideología, la afiliación sindical, la orientación sexual o la salud. Estos datos sólo pueden recogerse con consentimiento explícito y específico del usuario, distinto del consentimiento general de la app, y sólo si es estrictamente necesario para el servicio. Aquí la empresa falla en tres puntos: (1) pide un dato sensible sin justificación real para el servicio, (2) no informa con transparencia de la finalidad concreta ni de que puede negarse a darlo, y (3) no solicita un consentimiento explícito e independiente para ese dato en concreto. Lo correcto sería no pedir ese dato, o en su defecto, explicar la finalidad, hacerlo opcional y pedir un consentimiento explícito separado. Religion is a sensitive data category under the LOPDGDD, alongside ethnic origin, ideology, union membership, sexual orientation or health. This data can only be collected with the user's explicit, specific consent, separate from the app's general consent, and only if strictly necessary for the service. Here the company fails on three counts: (1) it asks for sensitive data with no real justification for the service, (2) it doesn't transparently explain the specific purpose or that the user may refuse, and (3) it doesn't request explicit, separate consent for that particular field. The right approach would be not to ask for that data at all, or failing that, to explain the purpose, make it optional, and request separate explicit consent.

DESARROLLO CORTOSHORT ANSWER

Una empresa sufre una brecha de seguridad el lunes a las 10:00 y no se da cuenta hasta el jueves a las 9:00, cuando lo detecta su equipo técnico.A company suffers a security breach on Monday at 10:00 and doesn't notice until Thursday at 9:00, when its technical team detects it.

¿A partir de qué momento empiezan a contar las 72 horas para notificar a la AEPD? ¿Y qué debería hacer la empresa además de notificar a la Agencia?From what moment do the 72 hours to notify the AEPD start counting? And what should the company do besides notifying the Agency?

Ver soluciónShow solution

Las 72 horas empiezan a contar desde el jueves a las 9:00, momento de la detección de la brecha, no desde que ocurrió realmente (el lunes). Además de notificar a la AEPD, la empresa debe comunicar la brecha a las personas afectadas si supone un riesgo elevado para sus derechos y libertades, explicando qué ha pasado y qué medidas se están tomando. The 72 hours start counting from Thursday at 9:00, the moment the breach was detected, not from when it actually happened (Monday). Besides notifying the AEPD, the company must inform the affected individuals if the breach poses a high risk to their rights and freedoms, explaining what happened and what measures are being taken.
